# CLAUDE.md — ollama-chat

A single-user React/Vite chat UI for a homelab Ollama instance, with a small Express backend
for opt-in session sync. See `README.md` for features and `docs/architecture.md` for the
component/topology map — it links out to a focused page per subsystem (chat & images, vocal
mode, storage sync, deployment) rather than one long file. `docs/adr/README.md` indexes every
non-obvious design decision — check it before assuming an "obvious" alternative wasn't already
considered.
