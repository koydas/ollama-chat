# CLAUDE.md — ollama-chat

A single-user React/Vite chat UI for a homelab Ollama instance, with a small Express backend
for opt-in session sync. See `README.md` for features and `docs/architecture.md` for how the
pieces fit together (with diagrams). `docs/adr/README.md` indexes every non-obvious design
decision — check it before assuming an "obvious" alternative wasn't already considered.
